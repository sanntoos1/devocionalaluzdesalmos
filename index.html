Antes de começar.

Algumas respostas para você saber como aproveitar o material.

Preciso ter conhecimento bíblico para usar o guia?+

Não. A proposta é usar uma linguagem acessível para acompanhar a leitura. Você pode começar mesmo que esteja desenvolvendo o hábito de estudar a Bíblia.

O guia substitui a leitura da Bíblia?+

Não. O guia é um material de apoio ao estudo devocional. Leia cada Salmo diretamente na sua Bíblia e use as explicações para aprofundar a compreensão.

Preciso estudar todos os dias?+

Você pode seguir no seu ritmo. O importante é separar um tempo realista para ler, refletir e colocar em prática o que compreendeu.

Como recebo o material depois da compra?+

As instruções de entrega devem ser informadas no checkout utilizado. Configure esta resposta com o processo real de entrega antes de publicar a página.
